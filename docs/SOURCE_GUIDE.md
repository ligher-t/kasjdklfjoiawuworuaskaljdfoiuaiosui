# 史料の探し方

更新：2026-10-30。siryou 原本はこのリポジトリへ複製しない。以下は依頼者の siryou フォルダーを再帰確認したときの索引で、PDF 24点・Markdown 2点を確認した。ローカル配布資料の存在確認であり、全ページを今回再読したという意味ではない。

## 使い方

1. 論点から下表のテーマとファイル名を探す。
2. 頁が記載されている場合はPDFページを開く。印刷ページとPDFページの両方が記録されている出典台帳項目では、それぞれの表記を維持する。
3. 個別の事実を引用する際は、data/parts/model/sources/references-entries-01.js〜03.js の SETTING_SOURCES を正本として使う。イベントの具体的な出典ID・頁・確度・留保をここへ重複転記しない。
4. 横断調査やWiki要約は調査の入口にする。公式設定の確認には、公式ストーリー・人物記録・告知へ遡る。非公式な本文アーカイブは日本語本文を探す補助であり、公式配信元とは区別する。
5. 台帳に頁がない資料は、引用前に目次・該当箇所を確認して出典台帳へ頁を登録する。内容を読めていない資料の頁を推測しない。

根拠区分は「公式説明」「個別の物語・人物記録」「二次資料」「分析・推論」「ゲーム内補完」を使う。公式動画を扱う二次報告も、動画の制作元が公式であることと、動画中の語り手・逸話・風刺の文脈を分けて記録する。
