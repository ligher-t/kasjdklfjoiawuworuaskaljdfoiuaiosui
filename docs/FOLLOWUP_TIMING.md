# 期限付き後日談の時期と本文

対象：Draft PR #5。2026-10-30の利用者提供ログでは、40歳時の子どもの源石片曝露に対する「一年後」の再検査が69歳、再延期後が102歳で表示された。学校の23年後の後日談、養育ネットワークの定期連絡にも初回用の年月表現が残っていた。

## 処理の契約

`js/events/dispatch.js` の `scheduledFollowupDueYear` は既存の期日を読むだけで、人生・乱数を変更しない。`nextScheduledFollowup` は通常の適格性・操作可能な選択肢・同月選択制限を通った候補だけを、期日の古い順で選ぶ。未解決の必須学校判断は従来どおり先に扱う。その後に期限付き後日談、その他の優先イベント、任意抽選と続く。

|対象|期日の正本|
|---|---|
|family_child_exposure_followup|対象児のexposureReviewYear|
|family_care_network_contact|養育ネットワークのcontactReviewYear|
|family_sibling_parent_support_conference|相談記録のdueYear|
|infection_workplace_review|職場相談のreviewDueYear|
|earth_discr_school_later|前の教室イベントの記録年＋after.min|
|life_ursus_school_aid_followup / adult_followup / aid_later|各先行イベントの記録年＋after.min|

これは「必ず約束の日に発生する」との保証ではない。進行再開後の最初の適格なイベント枠で優先し、死亡・連絡停止・年齢・地域・発生年／月・once・クールダウン・選択不可・同月選択済みの制限を突破しない。同時に多数の案件がある場合や接触不能・収容等では遅れ得るため、本文も実際の経過に合わせる。暦を巻き戻したり、未実施の診察・連絡を自動成立させたりはしない。

医療上の未解決案件は古くなっただけで消さない。子どもの再検査は存命・連絡可能で未解決の対象から選び、延期はその子の次の期日を更新、解決は保留を閉じる。新しい負傷ではexposureYearを新しい発生年へ更新する。単なる延期は発生年を変更しない。

## 本文の契約

- 再検査：選択対象として固定された子のexposureYearから経過年を算出。「一年待った」「傷が塞がった」を何十年後にも固定表示しない。現在の体調と再検査の予定を相談する。
- 養育ネットワーク：初回は家計分離後のreview_scheduled記録、その後は最後に連絡の取り方を決めたlastContactYearを使う。定期連絡を毎回「家計を分けて一年」と言わない。
- 学校：教室・避難の先行記録から経過年を表示。成人期の名簿後日談も「成人して間もなく」と固定しない。既存の歴史的な発生年上限・月制限を維持する。
- きょうだい支援相談：requestedYearからの経過で表示し、「昨年」を固定しない。
- 職場相談：disclosedYearからの経過を表示する。「職場を離れた年」は記録されていないため、開示年を離職年に読み替えない。
- 起点が不明・未来の場合、年数を捏造せず年月を限定しない導入を使う。期日・認知・相手の返答があるだけで医療結果や同意を推定しない。

既存の期日・発生記録を再利用し、旧セーブの修復・移行や新しい履歴アーカイブは追加していない。

## 確認範囲

既存の高評価 `v87_exposure_lifecycle.js` に短い回帰を追加。任意抽選が選択を出さない乱数でも、期日到来の再検査・養育連絡・学校後日談が選ばれること、期日前・死亡・連絡停止・クールダウン・once・年／月制限・選択不可・同月制限・必須学校判断を維持することを実際のslot判定で確認し、合格した。案件選択の読み取りが状態・乱数を変えないことも確認した。

29年／30年の再検査、6年ごとの養育連絡と初回1年、23年後の学校、12年後の職場開示、9年後の支援相談の本文を実際の本文解決器で確認した。延期・解決・新しい負傷の更新、別の子の非変更、JSON直列化後に期日が保持されることを確認した。後者はブラウザーの保存ダイアログ往復を意味しない。

`eligibility-rules.test.cjs` で既存の条件読取・状態／乱数保持の回帰も合格。構文確認も合格し、通常の版指紋更新を行った。動的本文を反映する既存イベント索引を再生成し、--checkで一致を確認した。実ブラウザー操作、全後日談の全分岐、自然発生率、提供ログの全文再生、1000人シムは今回の確認範囲外。PRはDraft・未マージを維持する。
