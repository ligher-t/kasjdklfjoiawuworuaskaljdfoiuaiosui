# P0：就学・学習経験・軍務の文脈

Draft PR #2の就学・進路・招集・後年の軍務と教育経路に関する判断根拠。年齢、給金、費用、抽選率はゲーム上の仮定であり、テラ全域の全国共通制度とは扱わない。通常の変更履歴はGit、受入証拠は `PR2_P0_P2_IMPLEMENTATION.md`、未完了事項は `../REMAINING_TASKS.md` に置く。

## 照合した経路と採用理由

## 従軍履歴の境界

`fl.veteran` は現行モデルの**従軍歴**であり、退役・実戦・戦争トラウマの証明ではない。入隊・初任務中に重傷で離れた場合にも従軍歴は残る。`retired` は明示的な離職、`trauma_war` は本文が示す戦闘や戦争被害と区別する。

消費箇所は `js/health/death-risk.js`、`js/health/mortality.js`、`js/audit/state-life.js` を照合した。現役の職業と従軍歴を別々に死亡抽選・診断情報へ用い、従軍歴だけで「戦闘職務中の死亡」を表示しない。これらの係数もゲームの仮定であり、個人が特定の戦場に居合わせた証拠ではない。旧セーブ移行は要求しない。

## 資料と解釈の限界

- `SRC_EDUCATION_ACCESS` は利用者提供の二次整理資料。費用・距離・身分・感染状態・言語・労働時間による教育アクセスの差を設計上の参照とし、国別の普及率・授業料・課程年数を確定しない。
- 『ウルサスの子供たち』ST-3冒頭の回想では学校と技術学校への進路、家族が語る世代差が描かれる。[ゲーム本文の非公式転記](https://shimadouma.github.io/astrhtml/events/act10d5/stories/ST-3.html)で本文を照合した。夢・回想と登場人物の説明を含む場面であり、全ウルサス・全時代の義務教育やテラ共通課程の根拠にはしない。
- 既存の第16章・第17章の資料は特定の危機や登場人物の説明であり、一般住民全体の徴兵年齢や全国一律の制度を示さない。志願・招集・契約・家族の関与は個別のゲーム場面として扱う。
- すべての登録イベントの逐語校閲や全国家の制度復元を今回完了したとは主張しない。上表の経路と、既存の教育・生活文脈・戦争死亡の関連境界を監査範囲とする。
