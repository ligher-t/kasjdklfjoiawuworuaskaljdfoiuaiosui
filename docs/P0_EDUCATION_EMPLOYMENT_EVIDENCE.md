# P0 教育・採用・感染就業の判断根拠

## 設計の境界
- **学習成果**（ep、知識、識字、技能）は学校や学院の**修了事実**ではない。特に初等教育の在籍開始を修了と見なさない。
- 修了・在籍・中断を既存のフラグと進学状態に接続し、資格要件の審査へは証明可能な履歴だけを渡す。学校外学習や徒弟技能を妨げない。
- 「医師・研究者」という共通職業ラベルの曖昧さを、応募先と担当役割による別判定で緩和する。医師資格の全テラ共通免許は想定しない。
- **感染状態、診断、雇用主の認識、応募の結果、実際に起きた差別**を区別する。医学的な感染から全職業を一括禁止しない。
- 地域別の職業重みは社会や法制度の確定統計ではない。史料で確認できる地域・組織の制約だけを対象にし、未知は制限しない。
- 既存の就業・資格・感染・職場差別の履歴は廃棄せず、これらを後年へ接続する。
