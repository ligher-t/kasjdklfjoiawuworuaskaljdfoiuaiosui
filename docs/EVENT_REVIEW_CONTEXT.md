# 選択の再確認・地域日常・感染認知の接続

## 原因と処理の境界

利用者提供ログの監査では、同じ慢性症状に対する緊急相談、子どもの進路相談、汎用日常の反復が確認された。既存の相談や認知記録を使い、選択済みの状況と、新たに判断が必要な状況を区別する。

### 医療と窓口

- `ask` の実際の選択解決後に、最後の回答・年・状況を `eventReviews[eventId]` へ保存する。表示、保留、適格性の照会だけでは回答済みにしない。各対象イベントに最後の一件だけを保持する。
- `illness_followup` と `life_medical_*` は、病状・活動中の病気エピソードと重症度、治療、診断、体力の帯、受診先・所在地・就業、生活費を残した費用余力を比較する。同じ状況なら最低5年空け、元の表示条件・クールダウンも維持する。5年後に必ず相談が発生する処理ではない。
- 緊急相談は、そのエピソードへの前回対応時の重症度と治療継続を保持する。相談期間が切れただけでは同じ緊急相談へ戻さず、新規エピソード、悪化、継続治療の中断で再び判断できる。通常の年次病状進行・医療費・回復・死亡リスクは継続し、相談を自動受診・自動回復へ置き換えない。
- 窓口の対象は `local_medical_capacity`、`v77_written_application`、`people_clinic_followup`、`site_clinic_contact_change`、`site_clinic_different_conditions`。同じ状況を年数だけで再質問しない。診療先・複数窓口の受入状況・既知の担当者、または応募時の勤務先・職種・書類を整えられる条件が変われば、元の条件の範囲で再提示する。再提示本文には前回の回答を添える。
- 状況比較は施設を新規生成・更新せず、既に準備された現在の施設・認知を読む。適格性照会で乱数や人生を動かさない。

### 家族

支援を選んでも `futurePlanYear` が設定されず、初回相談の候補に残り続けていた原因を修正。支援履歴と同時に初回相談済み・相談時の状況を記録する。

次回は最低3年後とし、成年への移行、就学・訓練の修了や予定変更、既知の仕事・居住地・感染認知・同居状態の変化がある場合に見直す。「三年後にもう一度話す」を選んだ場合は、変化がなくてもその約束を維持する。連絡終了・休止中や独立済みの子には強制しない。対象は期日・人物IDで安定して選び、別の子の未相談を一人目の回答で閉じない。再相談の導入には、その子へ前回行った支援を表示する。支援の申し出を本人の進学・就職・転居の決定へ読み替えない。

### 地域・職歴と日常の抽選

適格な日常候補に、現在の地域・職業条件を満たす場面、または実際の先行記録を持つ後日談がある場合、70%の優先抽選を設ける。残りは通常の全候補から選び、候補がなければ従来の日常へ戻る。分類は実際に選ばれる本文の条件も参照する。気分の抽選だけで地域の場面を落とさず、地域候補内に対応する気分があればそれを使う。

`family_daily_small_care` の重みは1.1から0.45へ変更し、個別の家族対象・本文と既存の間隔は維持する。地域別の独自制度や同じ接頭辞を量産する変更ではない。70%はゲーム内の抽選設計であり、全人生の地域イベント率を70%と断定する値ではない。

### 感染認知から制度的対応へ

既存のウルサスの摘発とリターニアの隔離通達を、現在地での本人の感染確定情報へ接続する。

- 現在地・地域・生活圏が合う当局／住居管理者の確定認知、または現在の契約先に一致する雇用主／職場の確定認知を参照する。
- 家族だけへの開示、噂、本人同定不明、以前の勤務先・別地域の認知を、この入口には使わない。雇用主の把握を自動的な当局の認知レコードへ変換しない。
- ウルサスの摘発は、工業・採掘区だけでなく上記の実際の認知がある現在地でも候補となる。既存の隠蔽・摘発・収容の分岐を使う。リターニアの通達は、私的な診断だけでは出さず同じ認知条件を要求する。
- 適格かつ操作可能な制度的対応は任意抽選より先に選ぶ。未解決の必須学校判断、期日到来の後日談、既存の優先イベント、同月の選択制限は保つ。
- 当局の把握は実際の通達・捜索の結果で既存の認知台帳に記録される。収容・隔離は既存の就労・賃金・移動制約を使い、フレーバーの罰点だけにはしない。全員を無条件に収容する処理や、NPC間の自動伝播は追加していない。

これは既存の地域描写を接続するゲームモデルであり、全国家・全時代の法的取扱いの確定ではない。原作根拠は対象イベントの既存referencesを維持する。

## 短い回帰と確認限界

既存高評価 `v87_exposure_lifecycle.js` に、実際の選択解決後の回答記録、同じ応募・受診案内の抑制と勤務先／受入状態変化後の再提示、安定病状と悪化・治療中断、子どもの修了・再相談の約束・別の子・連絡終了を直接検出する回帰を追加した。実際のslotで地域・職業・先行履歴の優先と汎用日常へのfallbackを確認する。

感染の回帰では、家族／元勤務先／噂／他地域からの誤接続を拒否し、現在の雇用主の認知から非採掘区の摘発が選択され、感染者の収容結果で当局認知と実際の年次収入0につながることを確認する。リターニアでは私的診断と現在地の住居管理者の確定認知を区別する。

上記の `v87_exposure_lifecycle.js`、`eligibility-rules.test.cjs`、明示的な判定サービス接続の `rule-api.test.cjs` が合格。構文確認・イベント索引の生成一致も合格した。回答記録のJSON直列化保持は確認するが、実ブラウザーの保存画面往復は確認していない。自然プレイの新しい頻度分布、全国家・全分岐、1000人シムは対象外。
