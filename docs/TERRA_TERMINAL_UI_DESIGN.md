# 生活記録端末 UI デザイン契約

この文書は『テラに生まれて』の**視覚・操作上の恒常的な設計原則**であり、未完了タスクの一覧ではない。現在の作業・課題は `REMAINING_TASKS.md` のみを正本とする。

## 体験の中心

普通のテラ住民の人生を読むための「民生用の記録端末を模したゲームUI」。作中に公的な万能監視端末や共通戸籍システムがあるとは主張しない。公式のアークナイツ画像・ロゴ・ピクトグラム・音源・フォント・スクリーンショットをゲームに流用せず、原作の人事資料・アーカイブを参照し、資料階層、分類記号、紙面の文字組み、独自図版と操作の手触りで表現する。一般住民の記録を扱う独自端末であり、全員をロドス所属とは扱わない。

優先順位は **人生を読む → 今の暮らしを理解する → 根拠と経緯を調べる → 状況に応じて選ぶ**。テラらしさのために説明不能な偽機器番号・偽公印を追加しない。

## 面の役割

- **DEVICE**: 画面外殻6〜10pxと上部の操作レール。表紙や選択画面にも暗い面を使い、資料面との役割を分ける。
- **DOCUMENT**: 人生のログ、家族、症状、収支、居住の既知の履歴。高コントラストで、長文読解を妨げる背景テクスチャを置かない。
- **COMMAND**: 進行、選択、中断保存、方針の編集。重要な操作ほど位置と面の対比で示す。
- 端末らしさを「全パネルに黒枠＋黄色線＋英語ラベルを貼ること」に還元しない。文字組み、資料の形、操作の状態と密度の差で伝える。

## 構図・文字・色の体系

- 左の人物票は氏名・年齢をコンパクトにまとめ、基本情報と全指標へ初期位置から目を通せる密度を優先する。中央の人生記録は広い読書面として扱う。右の生活概要は背景面に罫線で区切り、4資料への入口を優先する。一般的な体力指標の説明は医療資料と開閉式の読み方に残し、概要では反復しない。中間幅では概要ドロワー、小画面では既存の本人／人生／暮らしタブへ組み替える。
- 面は灰白色 `#f7f7f4` と灰色、操作外殻はグラファイト `#171a1f`。暗色テーマは `#22252b` の記録面を使う。金色 `#e3b451` は開始・再出生・保留復帰とキーボードのフォーカス表示へ限定し、通常の戻る操作は中立色、分類と速度の選択中は白黒反転、青は暦の進行・指標へ用いる。警告は文言と罫線を併用し、装飾のために重大度を変えない。
- 文書見出し、人物票、本文、補足の役割で文字の強さを分け、ツールバーにもある氏名・年齢を巨大化して基本情報を押し出さない。本文は原則16px以上、人生ログは行間1.85、選択の状況文は1.9とする。数字は桁幅を揃える。日本語本文は通常の太さ、見出しは太字、分類英字は幅の狭い書体と字間で役割を分ける。英字は表紙・分類・索引へ使い、日本語操作名を置き換えない。
- 薄いドット・格子・ハッチング・裁ち落とし線を表紙・余白・索引へ使える。本文の背後は静かな読書面に保つ。分類番号は実際の資料順であり、公的登録番号や機器番号ではない。人物名の省略は狭い現在地・操作ヘッダーだけで行い、人物票と元資料は全文を残す。

## 人生の記録

- 縦型タイムライン。年は区切り見出し、月と年齢は本文より小さいメタ情報。本文は列全幅を使う。
- 現行ログは `#lg li` の最新順で、日時の `<b>` を保存・復元で読む。年月の視覚加工がログ本文や保存を変えてはならない。
- 良い・悪い・日常の絞り込みは従来の記録属性に基づく。色を人生の客観的善悪として説明しない。分類情報がないイベントに架空の分類を創らない。
- 記録が数百件あっても毎tickすべてのログDOMを再構築しない。本文のフォント縮小や省略で可視件数を稼がない。

## 現在の生活と詳細台帳

- 左: 個人の基本情報・主要指標。中央: 人生ログ/詳細台帳。右: 今の体調、生活費、学び、住まいの概況。
- 状況カードは**現在の本人が体験・把握できること**を優先する。「診断記録なし」と「健康」は同義でない。
- 右の要約を選べば、中央で `現在の状況 → 経過/要因 → 記録` を読む。詳細台帳からは一度で元ログへ戻れる。
- 診断前の鉱石病、未着の訃報、未確認の他者の意思、開発用内部フラグを人物向け表示へ漏らさない。
- 本人の金銭と養育世帯の資金は別。地域指数は作中の公式統計としては扱わない。
- 中央の危機バナーと年代ジャンプ索引は置かない。重大な状態は右概要の具体的な文言と「要確認」で示す。保留選択の復帰導線、年別見出し・フィルタ・終幕の4項目目次は維持する。
- 台帳は文書全体の単一スクロールを使う。900px以上では細い資料ディレクトリと本文、狭幅では初期折り畳みの索引へ組み替える。分類・現在地・日付は共通の表示定義と実状態から生成する。既存見出しへの索引は実在するIDへ移動し、閉じた資料を開いて見出しにフォーカスを置く。戻る操作は共通ヘッダーの一つとし、保留選択への復帰は独立させる。
- 台帳の本文は単一列の資料として、現在の状態と固有の数値、見出し、罫線付き項目、経過の順に読む。要約と同文の数値欄を繰り返さず、入れ子の枠や小さな二列カードを増やさない。
- 生業・家族・地域の表では明示的な「記録なし」だけを一つの「未記録の項目」へ折り畳み、内容を保存する。家族の「なし」は「その他の関係・経過」へ分け、未記録と混同しない。同居者なし、ゼロ、未診断、安否未確認は本文に残す。
- 開示・施設で出会った人・本人に伝わった事件の記録がまだない場合は、元の資料DOMを「未記録の資料」へまとめる。本人の記録ができた資料は本文へ戻す。原本のIDを維持し、情報を捏造せず、再描画だけで閲覧中の開閉やフォーカスを失わせない。

## 起動と終幕の資料

- 広い起動画面は独自の移動都市図版を持つ表紙と出生操作を左右に組み、開始・再開を優先する。狭幅では表紙と余白を短くする。「歩み方」「世界設定と数値の前提」「資料の根拠と作品について」は用途別に開く。非公式二次創作の表示は初期画面に残し、詳しい注意と確度の定義も読めるようにする。
- 終幕は名前・享年・期間の見出しと再出生／保存、4項目の目次を維持する。要約には最後に記録された3件までの節目と、全節目を読む導線を置く。物語上の重要度を勝手に判定して新しい節目を作らない。
- 長い要約は「生い立ちと暮らし」「生業・学び・残したもの」「家族と人とのつながり」「身体・経験・最期」の4資料に分ける。最初の資料を開き、他は必要に応じて読む。家族は親・きょうだい・子・配偶者等に区分する。文章を切り捨てず、指標・比較・元の人生記録・JSON保存へ到達できるようにする。
- 死亡後の要約も、未診断のモデル感染を診断記録として明かさない。診断記録がないことを陰性の証明としない。

## 端末の仕上げ・シンボル・動き

- 人生記録には `LIFE RECORD / TERRA / CHRONICLE`、資料には分類英字と実際の順番、終幕には `ARCHIVE / INDEX` を使う。ディレクトリ表現を不要な補助ラベルと一律にみなさない。
- 独自SVGは移動都市の情景、居住資料の構造イメージ、終幕の資料束の3系統。居住図は実地図・位置・距離を示さず、本文にもその性格を明記する。図版の失敗が開始・閲覧を妨げないよう寸法と代替となる本文を保つ。
- 体調は医療記録、生業は経歴ファイル、家族は本人から分岐する関係、居住は都市基盤の記号。概要・ディレクトリ・資料・終幕で分類を揃え、小さな操作アイコンと大きな資料分類の記号を区別する。装飾は読み上げから除外し、日本語ラベルを残す。
- 経歴図は既存の `lifeChapterRecords` の仕事・技能・所属と、`socialLearning.yearlyHistory` の有効な年月・年齢・通学・読み書きの記録を年月順にまとめ、直近4件まで。記録された年の学びは全件を開いて読める。記録のない年や未来の記録は補わない。関係図は `lifeSummaryFacts.familyRecords` の公開可能な続柄と状態を使う。元の全文は下の資料に残し、相手同士の関係、未着の訃報、未診断感染や内心を補わない。
- 進行ランプは実際の進行・停止・選択待ちを反映する。狭幅の速度操作は開閉式とし、終了後は不要な進行操作を隠す。架空の通信・同期・権限状態を足さない。
- 押下は150ms、資料入場・分野切替・選択・保留復帰は220ms、表紙図版は600ms、終幕の資料束は450ms。一度の表示操作で再生し、値更新では再生しない。フォーカスと入力を演出待ちにしない。
- 「画面の動き」の既定はシステム追従。低モーション環境では完成形を即表示し、明示的な「演出を使う」だけが端末演出を有効にする。設定は人生セーブの外へ保存し、人生・RNG・保留選択を変えない。点滅・疑似ロード待ち・自動再生音は追加しない。

## 入力・表示設定

- 情報密度の3段階セレクトは廃止し、人物情報・6指標・4分野台帳への入口を常時維持する。テーマ、表示間隔（コンパクト/標準）、台帳閲覧中の自動停止を人生セーブ外のUI設定として持つ。
- タイトルでは「生まれる」が主操作。主要開始・再開導線はデスクトップの初期画面内を目標とする。
- 出生年は最初から選べる。101年の巨大プルダウンではなく、年の数値入力・±1年・範囲スライダーを同期させた単一の操作を置く。初期値1077年。「この年に生まれる」を唯一の開始CTAとし、範囲外の数値では出生しない。
- 上部操作バー中央に小さな**白い太線の輪郭を持つ45°回転正方形**を非操作装飾として置く。ファン向けの控えめな幾何学的合図であり、原作のアイコン素材を流用しない。狭い画面でも文字や操作に重ねない。
- 選択時の本文と選択肢の可読性、フッターの中断保存・縮小、保留からの復帰を保証。1〜9キー、Tab、Esc、無効理由、二重選択防止を保持。
- 選択は暗い見出し帯と年月、通常の太さの状況文、番号／行動文／矢印を分けた選択肢、固定フッターで構成する。選択面と番号はフォーカス・押下で反転し、すべての行動を同じ強い色で塗らない。選べない理由は行動の下に置く。行動文に含まれる費用や条件を省略せず、効果値・未来の結果を独自に推定して付け加えない。長文と9択は別々にスクロールでき、主操作を画面内に残す。
- 表示更新とテーマ・間隔変更で人生状態やRNGを変えない。台帳の自動停止は初期オンで、入場時の速度を保持して停止する。カテゴリ切替では停止を維持し、退出時に選択待ち・死亡・手動速度変更がなければ元速度へ戻す。自動停止の設定は人生セーブへ書き込まない。
- 指標はラベル／ゲージ／現在値／増減の固定列で示す。知識と読み書き、学歴と学習経験、健康と診断の違いは、指標のそばの一つの開閉資料から読めるようにする。月表示は空の状態でも領域を確保し、進行開始で操作レールを揺らさない。
- 終幕の健康・幸福は0–100、純資産は独立した実額の龍門幣目盛・0基線・実際の最小最大値で示す。資産の目盛は等間隔の読みやすい十進数とし、数字の桁数に応じて余白を確保する。グラフの文字を狭幅で縮小せず、横方向の閲覧領域をキーボードでも操作できるようにする。凡例は色と線種で区別し、短い履歴の数表は全件、長い履歴は表示数と全件数を区別する。
- 出所資料から同年のログへ移動するときは、スクロールとフォーカスを合わせる。移動先が見つからない通知は操作した資料のすぐ下へ出し、遠い資料末尾を探させない。スクロール演出は低モーションを尊重する。
- 1920×1080、1440×900、1024×768、768×600、390×844、360×900、200%表示を確認。狭い画面で主要操作を画面外へ追放しない。
- 文字のコントラストは通常4.5:1以上、重要なUI輪郭は3:1以上を基本とし、色だけでは状態を表さない。

## 現行コードの接続点

`index.html` はDOM IDとロード順、`js/ui/render.js` は表示の更新入口、`js/log/messages.js` と `js/save/slots.js` はログ保存契約、`js/ui/summary-view.js` は既知情報の射影、`js/ui/terminal-navigation.js` は詳細画面へ移すだけのナビゲーション。イベント・選択枝・乱数・保存の計算をナビゲーション側へ移さない。

現在のCSSは `style.css`、`ui-redesign.css`、`terra-identity.css` に跨っており、必要な状態を保ちながら責務単位に整理する。新たな大規模な第4層のオーバーライドを増やさない。
