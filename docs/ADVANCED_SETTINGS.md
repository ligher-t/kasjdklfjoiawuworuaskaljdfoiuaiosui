# 高度な設定の設計根拠

## 設定と保存先

既存の「表示設定」を「設定」へ改称し、折り畳みの「高度な設定」を置く。人生の進行に作用する4項目は `S.playSettings` に保存し、同版の中断・再開で復元する。ブラウザーの `terra-play-defaults-v1` は次の新規人生の初期値にだけ使う。別の人生を読み込むと、その人生の設定を優先する。診断用ヘッドレス実行は固定の既定値で開始する。

| 項目 | 既定値 | 適用 |
| --- | --- | --- |
| 義務教育自動化 | ON | 初等・前期中等課程 |
| 高等教育自動化 | OFF | 後期中等・大学・職業・アーツ課程 |
| 通常イベントの頻度 | 中 | 翌年度の通常枠 |
| ランダム選択イベントの比率 | 中 | 翌年度の通常枠の抽選 |

設定画面を開くと停止し、閉じると入る前の速度へ戻す。未解決の選択、重要通知による停止、台帳の自動停止がある場合は再開しない。設定変更は既存の保存経路を使う。設定画面は縦スクロールでき、初期化は高度な設定に限る。テーマ・間隔・演出・台帳設定を初期化しない。

## 希望から修了まで

各段階の最初の進路希望は表示する。希望後の案件だけを対象に、既存の募集照会、資格・書類・言語・保護者・経路確認、出願、受験、合否、入学契約、請求・納付・在学記録を使う。表示済みの選択は設定変更で確定しない。手動へ戻すと、未解決の案件を通常の選択へ戻す。

同じ居住地域内の現在地と隣接地を調べ、現在地、初年度学費と受験料、往復通学時間、募集IDの順に候補を比較する。保護者の拒否や実際の不合格を別校への再抽選で取り消さない。入学契約に必要な費用が不足する場合は、既存の照会で実際に提示された返済不要の支援のみ検討する。借入、寄宿、転居、外国への進学は自動で行わない。

別地区の受験は指定月まで待ち、実際の到達可能性・往復交通費の決済を確認して受験日を記録する。合否は既存の月次サービスが翌月以降に回答する。決済・受験・入学を重複実行しない。

在学中の単位、出席、年度学費、卒業資格は既存のライフサイクルが判定する。卒業審査不足は既存の追加年度上限内で留年し、続く学費判定も処理する。年度支援は既存の個別減免確率32%を、在籍と年度ごとの固定抽選で一度だけ判定する。支援がなければ休学、復学条件が整えば復学し、在学・休学期限による終了を通知する。通学先の変更が必要になった場合は学籍を残して休止する。受入校との契約なしに転学を成立させない。学校生活や人間関係の選択は自動化の対象外。

## イベント数と優先イベント

通常枠の元の年次数は幼少期1～2、成人期3～6。極少／少／中／多／極多の倍率は `1/3, 2/3, 1, 1.5, 2`、端数は確率丸め、上限12枠とする。「中」の通常枠生成は元の乱数呼び出し順を維持する。選択イベントの基礎確率16%に `0.25, 0.5, 1, 2, 4` を掛け、各通常枠で4%／8%／16%／32%／64%とする。これは通常抽選の確率であり、全表示イベントに占める実測比率ではない。

当年度の適用値と月次サービス専用枠を `S.eventSchedule` に保持し、途中の設定変更や再開で当年を再抽選しない。通常枠のない月にもサービス専用枠を置き、移動、通学・受験回答、歴史情報、期限付き後日談、強制・優先選択を処理する。サービス専用枠で任意の日常イベントを追加抽選しない。1か月1選択の制約と既存の優先順を維持する。したがって強制・優先イベントを含む表示総数を固定の上限にはしない。

## 追加したUX設定

ブラウザー共通の `UI_PREFERENCES` に保存し、人生の乱数を消費しない。

| 項目 | 選択肢・既定値 | 動作 |
| --- | --- | --- |
| 選択確定後の進行 | 従来どおり（既定）／選択前の速度へ戻す／停止する | 後2者は選択開始時に速度を記憶して停止し、確定後の方針を指定する |
| 重要な通知で一時停止する | OFF（既定）／ON | 家族の死亡、新しい診断、学校の中断・継続不能などで停止する。明示の進行操作で停止理由を解除する |
| 自動進学の通知 | 簡潔（既定）／詳細 | 簡潔は節目の結果だけ表示する。手続・会計・合否の実記録は保持する |

## 確認範囲

`advanced-settings.test.cjs` は5段階、優先月、実入学・保護者不在・資金不足・受験日と翌月回答・留年と学費の連続判定・保存復元・設定初期化・通知停止を直接確認する。`ui-choice-presentation.test.cjs` は3種類の確定後速度と設定の停止／再開を確認する。既存の教育完了、学校進級、期限付き選択、月次滞在の検査を対応する境界の証拠として使用する。

独立したlocalhostのテスト人生をVivaldiの1920×1080画面で操作し、義務教育ON・高等教育OFF・頻度中・比率中の初期表示、頻度「少」の保存通知、末尾の通知設定と初期化ボタンまでのスクロール、Escapeで元の設定ボタンへ復帰、最初の希望から追加の選択なしで正式学籍1件・監査正常となることを確認した。利用者の保存は使っていない。小画面・スクリーンリーダーでの直接確認と長期の頻度分布測定はこの証拠に含まない。
