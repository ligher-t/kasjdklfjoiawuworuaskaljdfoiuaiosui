# P0 再実装：教育段階・大学入試・学校差別の資料と検証

更新日：2026-10-29。対象：Draft PR #5。**未マージのDraft PR #5。実装の確認とブラウザー受入の区別を維持する。**

## 原則

出生時の階級、養育者の資金と意思、通える学校、本人の学習履歴、感染や種族による排除を人生の連続する条件として扱う。学習点は修了資格ではない。中退・退学・不登校の人物も、技能習得や複数年の学び直しによって社会的な能力を得られる。

- **公式／本文由来**：『ウルサスの子供たち』「夢の中で」にはソニアの七年生、九年生修了後の継続進学と技術学校の選択が登場する。日本語本文閲覧：https://shimadouma.github.io/astrhtml/events/act10d5/stories/ST-3.html
- **オペレーター人物記録由来**：ウインドフリットは学費を貯めて中学に進学、転校、優秀な成績を経てクルビアの有名大学へ入学し、卒業後に就職。転記：https://terra-archive.net/ja/operators/char_433_windft
- **ゲーム上の仮定**：初等6年、前期中等3年、後期中等3年、大学一般3年／選抜4年、技術・アーツ専門校3年。全テラの法定義務教育年限ではない。
- **ゲーム上の仮定**：各年の授業料、学校の受入条件、学力閾値、社会的排除の確率。世界観から制限の存在は描けても、すべての学校の制度を確定できるわけではない。

## 実装された状態と処理

- `js/education/lifecycle.js`：`educationPath` と `educationDecision` の状態機械。学校ごとの `startedYear`、`stageStartYear`、`yearsCompleted`、`status`、`completed`、`equivalency` を保持。
- `js/life/annual.js`：年次フェーズで必ず教育を処理。月次抽選で学費と進級を放置しない。
- `js/events/dispatch.js`：6歳の入学希望、前期中等修了後の進路、学費不足、学校施設の転学、修了評価を通常の抽選より優先する。小学校入学・後期中等への進路判断はプレイヤーに表示する。
- `data/base/confinement-and-education.js`：大学・専門校のレベル別試験と正規中等修了条件。旧 `uni_fee` 等は二重課金を防ぐため非表示。
- `data/base/childhood-attitudes.js`：6歳の入学希望を本人が選ぶ。入学できない場合も選択肢と理由を表示し、実行不能にする。家事を選んだだけで現金を生み出さない。
- `js/life/annual/personal-amounts.js`・家計コード：フルタイム学生への自動就職抑止、在学開始時の常勤整理、本人・家計が合算で学費を払う処理と各会計への実負担記録。減免は所得ではなく授業料への支援として別記する。
- `js/social/infection-awareness.js` と `js/education/lifecycle.js`：感染の事実、本人の診断、担任への開示、学校施設が診断を把握したこと、学校側の判断、実際の学籍終了を分ける。診断フラグだけでは排除しない。`js/ui/ending.js` は在学中死亡の学籍終了も担当。
- `js/audit/state-basic.js` とログ：根拠のない修了、期限の異常、在学中の常勤職、卒業情報の整合確認。

## 地域・施設・年代と差別の扱い

19地域それぞれに `EDUCATION_REGION_PROFILES` を持つ。全地域共通の `REG[].st` だけから学籍を判定する方式は使わない。入学先の学校施設の状態（`activeFacility`）、在籍者の生活圏、年代ごとの学校受入のゲームモデル、学籍・学力・学費、サルカズの出自／ヴィクトリアのターラー系文化的帰属を分けて判定する。局所的な施設閉鎖時は別施設 `alternativeFacility` を確認し、本人に転学継続か通学中断かを選ばせる。

- **個別の感染認知**：`infectionAwareness` に学校を受け手として記録された確認情報だけを学校側が知り得る。個人に診断があっても申告されていない場合、学校へ自動的に通知しない。担任個人への相談 `school-contact` を直ちに学校の公式把握へ拡大しない。転学先へ古い学校の情報を自動伝播させない。
- **施設・募集区分・年代**：受入方針を生活圏の学校施設、教育段階、年代に結び付ける。記録された拒否と、その後の退学・転学を履歴へ分ける。大学・専門校の条件には近隣の初等学校の休止を流用しない。
- **感染・種族差別の確度**：各地域の `infection: deny/conditional`、`infectedChance`、学校の受入抽選、サルカズ・ターラー系への確率的補正は**すべてゲーム上の近似**であり、国家の法定一律禁止、全学校の統計または原作の明文化された入学規則ではない。旧実装の「カズデル以外のサルカズは受入確率を一律2.5%、ヴィクトリアのターラー系は一律8%へ落とす」補正は撤廃した。代わりに学校施設・教育区分・年代による変動幅のある選考モデルを使い、排除を必然にはしない。数値は原作の実測値ではない。特にカズデル、サーミ、各国の農村／都市／組織附属校は制度の未確認部分が大きい。原作史料の個別事件を国全体の確定制度に変えない。
- **史料とモデルの境界**：『ウルサスの子供たち』の学校生活、ウインドフリットの転校と大学進学は、実在の進路例であって全年代・全国共通課程の根拠ではない。日本語版と日本語訳の固有名詞を区別する。提供された2026-10-28教育・差別調査は横断的な二次整理として参照する。

法定義務教育年数、学校人口比、感染者の公式受入割合、個々の架空学校の実在は確認できないため、史実として断定しない。

## 明示的な設計判断

- 学習に課した年数・費用と入学・卒業結果を分離する。高い学習点だけでは大学に入学できない。
- 大学の試験確率は知識・識字・専攻に必要なアーツ技能と学校水準から評価する。「生まれつきの知能」や人格価値として解釈しない。
- 地域学校・一般大学と、より厳しい選抜大学・高水準アーツ学院を同じ選考としない。
- 初等→前期中等は基本自動進級。後期中等では進学・仕事を選ぶ。中等以上の学費不足は退学を基本とし、制度がある地域では休学を選べる。
- 社会人向け三年間の準備課程は正式の大学卒業ではなく、修了と能力評価を経た同等資格。単発の夜学では得られない。
- 通学を妨げる学校・家庭・感染者差別は、本人の能力と切り分けて履歴に残す。

## 今回の境界実装

- 6歳で入学できなかった人物は、学校への在籍と修了を持たない。8歳以降の遅い入学、16歳以降の複数年準備課程、氏族・職場・徒弟による学校外の学びを区別する。中等課程の中断者は20歳まで再入学を申し込める（施設・学費の条件付き）。単発の夜学は同等資格にならない。
- 小・前期中等から後期中等への道は年次状態で継続し、後期中等への進路はプレイヤーが選ぶ。審査・修了・退学・感染者排除・学校閉鎖・転学・学費支援の履歴を別々に保持する。
- 同居家族と本人の実資金を合わせた学費納付が可能。支出の自己負担・家族負担と不足分の学校支援は混同しない。制度を仮定した地域での減免申請は抽選結果を伴い、必ず成功するものではない。
- `family_launch`、14歳の工房見習い、ウルサスの同級生救助、リターニアのアーツ授業、複数の日常文について、就学・就労状態と文面を整合させた。働くことを検討しただけで雇用や給金が確定することはない。

## 2026-10-30監査指摘：再入学・実履修・勤務縮小の統合修正

利用者提供の1000人シムで報告された「在籍記録のない課程を修了」4例と勤務縮小監査1例を受け、原因を短い状態遷移で直接確認した。各seedの全生涯・乱数列を再実行したという意味ではない。

- 前期中等への再入学もgeneral-schoolの在籍記録を開始する。初等からの継続進級では既存の在籍を保ち、退学後の再入学は新しい在籍となる。修了の例外や資格監査は弱めない。
- `fundedYear`は授業料を確保した履修年度、`yearsCompleted`はその年度を終えて計上した実履修年数。入学・進級・減免・契約学費借入・復学は年度の開始として記録し、翌年の年次処理で一度だけ履修を計上する。未納の見送り・休学・飛ばした暦年は履修に加算しない。修了は必要履修数を満たしてから能力評価へ進む。
- 通常の初等6年→前期中等3年、後期中等3年、大学一般3年／選抜4年などの年限は維持。最終年度の履修を計上してから修了するため、修了のためだけの余分な授業料は取らない。留年は追加年度の費用を確保してから履修する。修了済みなのに実履修不足、未来のfundedYearなどを状態監査で検出する。
- 正式在学への入学・復学は勤務縮小フラグと開始年を両方解除する。働きながらの準備課程は仕事と勤務縮小を維持する。
